# Examples

Explore these practical examples to learn how to build AI agents with the Go SDK.

| Example | Description |
|---------|-------------|
| [Basic Agent](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/01_basic) | A minimal example showing how to create and run a simple agent. |
| [Function Calling Tools](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/02_tools) | Demonstrates how to equip agents with tools (Go functions). |
| [Agent Handoffs](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/03_handoffs) | Shows how multiple agents can work together by handing off tasks. |
| [Lifecycle Hooks](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/04_lifecycle_hooks) | Learn how to use hooks to intercept and instrument agent execution. |
| [Config & Usage](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/05_config_usage) | Advanced configuration options and usage tracking. |
| [Structured Outputs](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/06_structured_output) | How to force agents to return data in specific JSON formats. |
| [Complex Schema](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/07_complex_schema) | Handling complex nested data structures in outputs. |
| [Guardrails Demo](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/08_guardrails_demo) | Implementing safety guardrails for production agents. |
| [Sessions Demo](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/09_sessions_demo) | Maintaining conversation state across multiple turns. |
| [Advanced Features](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/10_advanced_v02) | Showcase of v0.2.0 features working together. |
| [Conversations API](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/11_conversations_session) | Using the new Conversations API for session management. |
| [Error Handling](https://github.com/MitulShah1/openai-agents-go/tree/main/examples/14_error_handling) | robust error handling strategies. |
